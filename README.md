# ShortRangeMicroDrone
**Group 8: Design of a Short-Range Folding Micro-Drone**

## Project Overview
This repository contains the design, simulation, and control files for our short-range folding micro-drone. Developed as a capstone engineering project at Hacettepe University, this repository covers the complete development lifecycle—from the structural folding frame design to the implementation of custom flight control algorithms.

## Key Features & Capabilities
* **Folding Frame Architecture:** Designed for portability while maintaining structural integrity and ideal thrust-efficiency.
* **Custom Flight Controller:** Monolithic flight controller implementation powered by high-performance microcontrollers (Teensy 4.1 / ESP32).
* **Advanced Control Systems:** Features custom-tuned PID loops, Madgwick filters for accurate state estimation, and DShot protocol integration (with digital integer inputs) for precise motor control.
* **Tested Flight Modes:**
  * Manual Mode
  * Position Hold Mode (IMU Only)
  * Altitude Hold Mode
